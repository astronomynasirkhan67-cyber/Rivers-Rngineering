# REA Desktop

A Windows desktop app (GUI) for analysing Android APKs. It wraps the
[REA](https://github.com/morluto/rea) engine - the engine, Node 22, JDK 21 and
JADX are all bundled, nothing else needs to be installed.

## Get the app (no computer needed)
1. Upload all these files to a new GitHub repository (keep the `.github` folder).
2. Open the **Actions** tab -> **Build Windows App** -> **Run workflow**.
3. When it finishes (about 10 to 15 minutes) open the run and download the
   **REA-Desktop-Windows** artifact. It contains the installer `.exe` and a `.zip`.

Requires Windows 10 or 11, 64-bit.
